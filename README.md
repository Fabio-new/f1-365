# F1 365 — Versione 3
Portale Formula 1 responsive, pronto per hosting statico come Vercel/GitHub Pages.

## Struttura
- Home, News, Calendario, Risultati, Classifiche, Piloti, Team, F1 Live
- SEO base, sitemap, robots.txt, 404
- `data/data.json` come base per il collegamento a un'API/CMS

## Pubblicazione
Caricare il contenuto della cartella nel repository GitHub e importare il repository in Vercel.
Nota: i dati presenti sono dimostrativi; per un sito editoriale reale vanno collegati feed/API/fonti autorizzate e verificabili.
